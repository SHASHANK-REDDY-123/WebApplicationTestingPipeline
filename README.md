# Web Application Testing Pipeline

A college-project web application demonstrating Continuous Integration.

## Run locally
1. Install Node.js.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm test`.
5. Run `npm start`.
6. Open `http://localhost:3000`.

## Pipeline
Code Commit -> GitHub -> Jenkins -> Jest Tests -> Quality Gate

## Outcomes
- CI concepts
- Jenkinsfile usage
- Quality assurance
